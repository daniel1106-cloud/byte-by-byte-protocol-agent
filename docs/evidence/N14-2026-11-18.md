- 네트워크가 격리된 컨테이너에서 서버를 서로 다른 임시 루프백 포트로 3회 기동했다. 매번 N10 원본 클라이언트로 캡처 당시의 정상 세션 6개를 실행해 비공개 기준 출력과 비교했다. 총 18회 모두 일치했고, 각 실행 후 서버 종료와 포트 접속 거부를 확인했다.

PR #11 코드(`01a789f` 이후)의 일반 clone 저장소 루트에서 다음과 같이 재실행한다. 현재 main의 `n09-check-pair.mjs`는 `practice` 준비만 받으므로 E1 쌍 검사는 PR #11 병합 후 main에서 가능하다. git worktree에서 실행하면 `.git`이 저장소 밖을 가리키므로 그 경로도 컨테이너에 마운트해야 커밋이 기록된다. 이번 재확인은 worktree에서 같은 이미지와 마운트로 `docker run`을 사용했다.


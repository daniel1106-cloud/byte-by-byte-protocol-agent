## 모델·크레딧 관련 확인

학교 공지는 학생 월3,000크레딧과 웹 접속 경로를 안내하지만 API 발급 여부·차감 환산률은 확인되지 않았다.
현재 프로세스의 API 환경변수는 설정되지 않았고, 연결된 메일 검색에서도 관련 발급 안내를 찾지 못했다.
학교의 로그인된 API/개발자 설정 또는 사용할 다른 제공사의 계정 정보 확인이 필요하다.

## 실행 중 표시된 메시지

- Python 로그의 `FAIL/ERROR`는 의도적으로 틀린 명세를 판정하는 테스트 출력이다. 전체 단위 테스트는 `Ran 25 tests`·`OK`다.
- Docker의 `Creating`이 PowerShell의 `NativeCommandError` 형식으로 표시됐지만 컨테이너 생성 및 테스트는 완료됐다.
- 명세 표시 명령을 붙여넣는 중 PSReadLine의 커서 렌더링 예외가 출력됐다. 이후 A/B의 명세·인용·unknowns가 모두 표시된 내용을 사용자 로그에서 확인했다. 앞서 저장된 통신 재실행 결과에도 영향이 없다.

## 재현 명령

회귀 테스트는 [N09/N12 인계 문서](../n09-wire-handoff.md)의 명령을 사용한다. 통신 재실행은 다음 명령을 A/B 각각 수행했다. `--out`은 기존 파일을 덮어쓰지 않도록 새 경로를 지정해야 한다.

```powershell
docker compose -f compose.n05.yaml run --rm n05 node scripts/n12-practice-bridge.mjs --analysis runs/gemini/2026-11-17T06-51-02-946Z/A-analysis.json --binary runs/gemini/2026-11-17T06-51-02-946Z/practice-server --out runs/manual-check/20261117-170450-405/A-client.json
```
